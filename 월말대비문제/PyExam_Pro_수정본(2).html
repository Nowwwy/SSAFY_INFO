⚡ 시험 직전 10분 핵심 요약[cite: 1]

시험에 가장 많이 나오는 5대 족보[cite: 1]

1. LEGB 스코프 탐색 순서: Local → Enclosed → Global → Built-in 순으로 식별자를 참조.[cite: 1, 2]
2. 인자 전달 순서: 위치 인자(Positional) → 기본값 인자(Default) → 가변 위치(*args) → 가변 키워드(**kwargs).[cite: 1, 2]
3. for-else 문: for 루프가 break를 만나 중단되지 않고 끝까지 완주했을 때만 else 블록 실행![cite: 2]
4. 반환 값(Return): 함수는 오직 하나의 객체만 반환. 콤마로 여러 개 반환 시 하나의 Tuple로 자동 패킹.[cite: 1, 2]
5. global 키워드: 함수 내부에서 전역 변수의 값을 수정하려 할 때만 사용. 선언 전 참조 불가![cite: 1, 2]
